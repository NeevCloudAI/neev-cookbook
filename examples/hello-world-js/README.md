# Hello World (JavaScript)

Create a sandbox, run a command, delete it.

```bash
npm install

export NEEV_API_KEY=...
export NEEV_ORG_ID=...
export NEEV_PROJECT_ID=...

npm start
```

Output:

```
sandbox 01a0ce3e-3647-7b74-95a5-71306fad29c8 is Ready
Linux 4.19.0-gvisor
hello from inside
deleted
```

For the Python equivalent see [hello-world-python](../hello-world-python).
