# Hello World (JavaScript)

Create a sandbox, run a command, delete it.

```bash
npm install

export NEEV_API_KEY=...
export NEEV_ORG_ID=...
export NEEV_PROJECT_ID=...

npm start
```

Output:

```
sandbox 01a1103d-a841-76f9-8841-19bd40a30336 is Ready
Linux x86_64
hello from inside
deleted
```

For the Python equivalent see [hello-world-python](../hello-world-python).
